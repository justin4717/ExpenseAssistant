Expense Assistant
Expense Assistant is a Laravel-based web application that helps you manage and categorize your expenses efficiently. It features AI-powered transaction categorization using OpenAI, allowing you to import bank statements (CSV or PDF) and automatically organize your spending.

Features
Import transactions from CSV or PDF bank statements
AI-powered automatic categorization of expenses (OpenAI GPT integration)
Manage budgets, categories, and receipts
User authentication and secure data storage
Getting Started
Prerequisites
PHP 8.1+
Composer
MySQL or compatible database
Node.js & npm (for frontend assets)
